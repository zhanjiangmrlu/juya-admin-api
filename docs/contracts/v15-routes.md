# V1.5 管理后端接口清单

由 scripts/export-v15-openapi.py 从实际挂载路由生成。本仓库冻结契约供管理前端和BFF分别更新其客户端。本任务不写其他仓库。

内部用户接口仅接受受信BFF HMAC正文。学生不能直接访问。收藏确认凭据须由BFF在最终保存的同一SQL事务内锁定并复验。HTTP预检查不能代替该步骤。
