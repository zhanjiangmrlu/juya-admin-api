## 执行裁决

1. 测试/生产使用不同身份和显式 EXPECTED_BUCKET 绑定，仅验证 juya-test；代价：生产验收等待单独授权与配置。
2. 原三仓计划增加用户授权的小程序上传兼容，使用统一记录和四个提交范围；代价：最终审查需覆盖四仓。
3. 真实 OCR/TTS 配置缺失且用户同意延期，只验证对象边界，不把本地模拟当真实供应商成功；代价：供应商部分待后续验收。
4. 共享已登记素材及历史版本保守保留，不自动回收草稿媒体对象；代价：孤立对象可能暂占存储，等待已证明安全的引用感知回收器。
5. 上传策略绑定 PENDING/false，客户端不能伪造可信安全结论；代价：完整素材业务确认等待可信验证流程。
6. 原计划第三步提交名称宣称生产验收，改为准确的测试环境验证名称并保留 CORS/浏览器待办；代价：原广义第三步不能标记完成。
7. 小程序日期相关权益测试失败与 OSS 无关，不越过用户的兼容修改边界；代价：全量套件仍有一项基线失败，需另行授权修复。
