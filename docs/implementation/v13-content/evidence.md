## 真实本地服务联调

后台开发服务 `http://127.0.0.1:18173`，管理 API `http://127.0.0.1:18000`，用户 API `http://127.0.0.1:18001` 和内容 Worker 保持运行。使用独立数据库 `juya_v13_local_e2e` 与 Redis 6398；自动测试使用独立测试库及 Redis DB 14，避免 worker 抢测试消息。未改动原 8000 服务及现有业务数据库。

真实浏览器没有替换 API 响应：登录、创建系列/场景、人工编辑保存、可点击片段、手机/平板预览、区间播放和发布均走实际服务。浏览器向 OSS 直传图片和音频因现有 bucket CORS 被阻挡；用独立 HTTP 客户端实际上传同一测试素材后，浏览器继续确认、编辑及发布。此结果属于“浏览器编辑/发布通过，浏览器直传待配置”，不能表述为完整浏览器上传通过。

素材使用合成图片与静音 WAV。服务端真实解码得到 2000 ms 音频；浏览器验证区间停止及逐句确认，不代表真实口语内容的标时质量验收。内容安全仅启用 local/test 且限定 `/fixtures/` 的显式测试门禁，没有调用云上内容安全；OCR 默认关闭，真实 HTTP 返回 `OCR_DISABLED`，人工路径完整可用。独立 HTTP 测试同时证明无效音频 422、未认证 401、TTS 409 和实际 Celery 批量标签任务完成、重放不重复执行。

联调场景 `01M3TZ916K2KYJY2MJHXSB1G9P`，修订 `01M3TZ917ED24HS86PGAWGZGVN`。发布前草稿编辑版本为 5，第一次发布内容版本为 1，两种版本不混用。用户登录采用隔离 SQL 会话与真实 JWT，不调用微信登录。通过管理 HTTP 授权正式月权益后，用户 API 读取固定发布内容、下载原图/整段音频、收藏权威词卡；错误修订/无关资源被拒绝，暂停权益后资源拒绝，预览仅返回双语安全白名单。7 项跨服务检查通过。

脱敏证据见仓库 `evidence/` 内 JSON 及预览截图；不保存账号口令、签名 URL、凭据或用户 token。

## 复现

在两个 API 仓库分别运行 `uv run ruff check .`、`uv run ruff format --check .`、`uv run mypy src`、`uv run pytest -q`。SQL/worker 用例显式配置 `JUYA_TEST_DATABASE_URL` 和 `JUYA_TEST_REDIS_URL` 为可清理的隔离资源，禁止指向业务库；先执行 admin-api Alembic 至 head，再测试共享数据库的用户 API。

在后台运行 `pnpm check`、`pnpm test --run`、`pnpm build`、`pnpm exec playwright test --project=chromium`；生产构建测试使用 `playwright.production.config.ts`。真实浏览器和 HTTP 联调工具保存在工作区 `.tools/v13-browser-live.mjs`、`.tools/v13_media_http.py`、`.tools/v13_cross_service_http.py`，其结果已脱敏保存。重跑真实测试需隔离服务和测试账户配置，避免混入生产环境。
