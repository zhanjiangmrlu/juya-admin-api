# V1.5 管理后端装配与验收边界

本仓库提供管理 API、BFF 内部契约与异步任务。接口清单和请求模型以 `docs/contracts/v15-openapi.json`、`docs/contracts/v15-routes.md` 为准。前端和小程序服务仍须消费这些契约,不能以本仓库通过测试视为跨服务上线。

## 数据与任务

增量迁移0017新增31张类型化内容、校对、导入、收藏引用、发音缓存和云计量表；0018新增运营排序、逐次收费账本唯一约束与发布范围表；0019为收藏主表增加明确内容范围，保留历史迁移和旧数据。最低结构版本为19。迁移只在私有测试数据库执行；共享环境升级由协调流程执行。0017与0018的downgrade拒绝删除不可变历史内容；0019仅在旧身份键无碰撞时可恢复0018，碰撞明确拒绝。必须停写/备份/online独占执行，中断续跑边界见v15-favorite-identity-migration.md。

导入上传先落盘并返回 202,校验和确认由 outbox/worker 执行。统一 ZIP 与独立素材 ZIP 使用私有磁盘展开,限制包体、展开总量、单文件、文件数和压缩比;API 与 worker 必须共享 `import_storage_path` 卷。DOCX 原句生成稳定句子标识;词汇表的来源原句或明确定位仅在能唯一匹配时形成关联,歧义保留草稿并进入校对。相同导入条目键改变义项或来源身份会拒绝覆盖,须使用新键。保存、映射和阶段完成在事务中核验租约与取消状态。

Celery 每 15 秒恢复可执行阶段与发音任务。broker 失败保留 outbox,已派发但未被领取的阶段有 120 秒期限,过期可重派。收费调用在领取阶段和预占预算后执行;UNKNOWN 不盲目再次收费。同一切片依赖失败后,管理员显式重新确认原边界可重试本地阶段,成功产物按依赖缓存复用。此操作不能重启付费任务。

## 媒体与人工确认

媒体角色由服务端绑定,词音和块音不能使用全文音频冒充。场景需要真实完整音频及每句独立文件;词卡不强制对话音频,短文只有独立全文音频。切片依赖源文件 SHA、固定音频版本、英文、人工边界和编码配置,旧文件不原地替换。

词义/发音文本确认、边界确认、听音确认、抽样校对分别记录。正常批量确认要求固定候选 hash/版本及服务器冻结的人工样本;修改候选会撤销集合资格。已发布快照只能复制成当前草稿,旧发布内容和收藏快照继续引用固定版本。

新增切片和校对严格要求素材 `PASSED`。内容审核关闭所产生的 `SKIPPED` 不代表通过审核,不能借此完成该流程;启用并配置实际审核提供方后才有真实可发布素材。音频版本可采用既有媒体系统人工确认产生的 `ACTIVE` 或历史 `SUPERSEDED`,切片听审仍独立要求 `CONFIRMED`。

## 授权与云计量

当前详情与资源基于实时账号、模块、发布状态、试看或权益判定。收藏复习单独验证所有权和固定快照,仅返回词图和词音;不能取得全文、句切片或受限原图。资源签名核验角色、版本、对象 SHA/HEAD,有效期不超过 60 秒且不超过权益剩余时间。BFF 最终返回仍须按内部契约在同一事务锁定并复核授权事实。

TTS、AI 和 ASR 默认关闭且预算为零。启用需配置凭据、模型/音色、配置版本及明确每日硬预算。管理员可通过 `GET /api/v1/admin/content/usage?period=YYYY-MM-DD` 查看预占、实际 token/毫秒/字符及 UNKNOWN 状态。未核实账单的实际金额保持 null,估算和供应商实账分开。测试使用假供应商,未调用真实收费服务。

## 验证

`uv sync --locked`、Ruff、mypy 和私有 MySQL 8.4/Redis 全套测试是代码门禁。全套覆盖率要求至少 80%,不删除覆盖范围或降低阈值。运行器仅创建和清理自己的容器、UUID 数据库及私有 Redis。真实 FFmpeg 验证文件解码、独立切片、时长、依赖失效和旧版本保留。

版权、人工听音质量、真实 ASR 时间边界、供应商账单、实际安全审核、OSS 浏览器 CORS/Range、BFF/微信设备和 Linux 部署属于外部验收。部署配置已提供 FFmpeg 与共享私有卷,本次没有构建或启动生产容器。
