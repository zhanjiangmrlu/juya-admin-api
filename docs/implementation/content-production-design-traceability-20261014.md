## 当前已确认的偏离项

1. `content-work-order-page.vue` 将 A20 结果与 A24 任务/用量放在同一个概览中，并通过四个切换入口承载 A19、A22、A22P/R。上述设计节点没有这张完整合并页；“内容生产工作单”不能认定为已对齐设计。
2. 上述页面的四个顶部切换入口及全宽状态下拉，是实现自行增加的页面组织方式。需求 16.7 允许筛选，但 A20 给出的是“需校对 / 全部问题 / 处理失败”的问题入口；不能拿筛选需求作为当前英文 Select 控件的设计依据。
3. `work-order-overview.vue` 把每条问题直接循环成修正按钮，导致截图中的同类入口重复；通用“请核对当前内容与原始输入”没有满足 16.5 的“哪篇、哪个位置、问题是什么、如何修正”，也没有还原 A20 的位置/问题两列。
4. A20 的异常结果职责与 A24 的阶段/用量职责必须分别对照验收。后台可复用现有批次数据与接口，但不能因此改变设计页面结构。

这些是本轮确认的差异，尚未修改产品代码。其他页面已找到对应功能与节点，但不因此声明所有控件、视觉、状态和导航均通过验收；后续逐页检查须以实际页面和设计上下文/截图为准。
